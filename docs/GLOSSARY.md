# Glossary

The words this product uses, with one meaning each. Code, database tables, API fields, UI text, notifications, the store listing and docs all use these terms, so an engineer reading the code, a user reading the screen and a reviewer reading the listing mean the same thing. Filled in during Phase 0 and kept up to date.

| Term (code and docs) | UI text in English | UI text in a second language, if any | Meaning | Not to be confused with |
|---|---|---|---|---|
| `workspace` | Workspace | (none) | Example row: the group of people and projects one subscription pays for. Replace it. | `project` |
